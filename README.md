# AI Resume Coach

AI powered resume feedback tool built with FastAPI and Gemini.AI based resume analysis with recommendations on projects,skills,job roles.

---

## Tech Stack

- FastAPI
- PyPDF2
- Gemini API
- Javascript
- HTML
- CSS
---

## Features

- Upload PDF Resume
- Extract resume contents
- AI powered resume analysis
- Resume score 
- AI based job,project recommendations
- Skill gap analysis
---

## Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/Devaswin-376/AI-Resume-Coach.git
cd AI-Resume-Coach
```
### 2. Create virtual environment
```bash
python -m venv venv
source venv/bin/activate   # Linux / macOS
venv\Scripts\activate      # Windows
```
### 3. Install dependencies
```bash
pip install -r requirements.txt
```
### 4. Set environment variables
```bash
Create .env file (do not commit it).
```
### 5. Start the server
```bash
uvicorn app.main:app --reload
```
### API will be available at: 

http://127.0.0.1:8000/docs↗️
